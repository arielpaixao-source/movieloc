H1. Linguagens Server-side: Uso do PHP 8+ para processamento de rotas, regra de negócio e manipulação de banco de dados no servidor.

H2. Técnicas e Métodos de Desenvolvimento: Aplicação da arquitetura MVC (Model-View-Controller) com Orientação a Objetos (POO), Namespaces e Autoload (PSR-4).

H3. Depuração e Tratamento de Erros: Utilização de blocos try/catch com exceções do PDO (PDOException) para tratar falhas de banco de dados de forma graciosa.

H4. Versionamento de Sistemas: Controle de versão efetuado com Git e hospedado no GitHub com commits estruturados por funcionalidade.

H5. Metodologias de Desenvolvimento: Uso da metodologia ágil Kanban para mapeamento de tarefas e entregas incrementais.

H6. Metodologia Ágil em Sistemas Web: Desenvolvimento iterativo dividido em Sprints/Etapas (Estrutura base -> CRUD Filmes -> CRUD Clientes -> Regra de Locação).

H7. Tipos e Formatos de Dados: Manipulação de dados estruturados em tabelas do MySQL (formatos VARCHAR, INT, DATETIME, ENUM).

H8. Conversão e Manipulação de Dados: Uso de funções nativas como number_format() para exibição de moeda (R$) e date() / strtotime() para formatação de datas pt-BR.

H9. Segurança da Informação: Uso de Prepared Statements com bind de parâmetros via PDO para prevenção de ataques de SQL Injection, e htmlspecialchars() contra XSS.

H10. Etapas de Implantação: Configuração de ambiente local no XAMPP (Apache/MySQL) e estruturação do diretório public/ para Ponto de Entrada único (Front Controller).

H11. Requisitos de Hardware e Software: Servidor Apache com extensão PDO habilitada, PHP 8+, servidor MySQL e navegador web moderno.

H12. Configurações no Servidor: Configuração do servidor virtual e apontamento de documento raiz no Apache via .htaccess / public/index.php.

H13. Políticas de Segurança: Isolamento de arquivos sensíveis (Models, Views e Controllers) fora da raiz pública exposta do servidor.

H14. Documentação da Implantação: Scripts SQL de criação do banco de dados e registros estruturados no repositório.

H15. Instalação e Migração: Gerenciamento de dependências via Composer (composer.json / composer dump-autoload).

H16. Validação do Sistema: Validação de entradas com atributo HTML required e verificações no lado do servidor (empty(), isset()).

H17. Identidade Visual e UX: Interface responsiva construída com Bootstrap 5, utilizando badges coloridos (success/warning/danger) e navegação intuitiva por Navbar.

H18. Linguagens de Interface: Uso conjunto de HTML5, CSS3 (Bootstrap CDN) e JavaScript nativo (onclick="return confirm()" para exclusões).

H19. Frameworks e Linguagens: Integração do framework de CSS (Bootstrap 5) com PHP e gerenciamento de autoloader do Composer.
